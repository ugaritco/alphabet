# Ugarit + Livewire Starter Kit

## Introduction

Our Ugarit + [Livewire](https://livewire.ugarit.com) starter kit provides a robust, modern starting point for building Ugarit applications with a Livewire frontend.

Livewire is a powerful way of building dynamic, reactive, frontend UIs using just PHP. It's a great fit for teams that primarily use Blade templates and are looking for a simpler alternative to JavaScript-driven SPA frameworks like React and Vue.

This Livewire starter kit utilizes Livewire 4, and Tailwind, but **does not include any authentication scaffolding**.
